# AttendanceDash Pro (Backend Foundation)

This directory contains the Python/FastAPI backend for AttendanceDash Pro, established during **Phase 1** of the architecture migration.

## Architecture

The backend strictly separates the **Domain** from the **API** and **Infrastructure**.

1.  **Engines (`app/engines/`)**: Pure Python modules containing the core mathematical and temporal logic for the academic domain. These engines do NOT depend on the database, HTTP requests, or external state. They receive inputs and return deterministic outputs.
2.  **Services (`app/services/`)**: Orchestration layer. Services fetch data from the database (future implementation) and pass it to the engines for processing.
3.  **API (`app/api/`)**: FastAPI routers that expose the service layer to the frontend.
4.  **Schemas (`app/schemas/`)**: Pydantic models defining the strong data contracts for the domain.

## Local Setup (Phase 1)

Currently, the backend consists purely of domain models and scaffolds. There is no active database connection.

1.  Navigate to the `backend` directory:
    ```bash
    cd backend
    ```
2.  Install dependencies (a virtual environment is recommended):
    ```bash
    pip install -r requirements.txt
    ```
3.  Run the FastAPI development server:
    ```bash
    uvicorn app.main:app --reload
    ```
4.  Visit the autogenerated API documentation at `http://127.0.0.1:8000/docs`.

## Testing

Domain parity test structures are located in the `tests/` directory.

To run tests (when implemented):
```bash
pytest
```
