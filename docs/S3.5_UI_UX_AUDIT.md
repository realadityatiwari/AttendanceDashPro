# S3.5 UI/UX Completion Audit

## 1. Executive Summary
S3.4 closed the core engine gap (`totP` lab stats, Firestore rules for `laboratory`/`academicEvents`, Service Worker asset list) with 67 passing assertions. This audit is a read-only forensic pass over the **user-facing surface**, verified live in a real browser (Puppeteer/Chrome headless) at **375 px (mobile), 768 px (tablet), and 1440 px (desktop)** against Firebase test accounts.

The math pipeline (Calendar → Attendance → Quiz) renders correctly and is verified. However, several **interactive surfaces are missing or dead** — most critically:

1. **Mobile date navigation is inaccessible** — `#mobileDateTrigger` carries an inline `style="display:none;"` that no JS overrides and that beats the responsive CSS rule (inline style > stylesheet). On ≤767 px the desktop date navigator is also hidden, so mobile users can never change the viewed date.
2. **Quiz-cycle switching UI is dead** — `#quizTabs` is an empty placeholder. `switchQuiz()` has no caller, the keyboard handler targets buttons that don't exist, and the Quiz Eligibility summary hard-codes "First Quiz". Users cannot switch between 1st/2nd/3rd Quiz eligibility periods.
3. **Laboratory logging UI is dead** — `data-action="logLab"` and `data-action="switchQuiz"` handlers exist in the global delegate but nothing ever renders those buttons. Lab cards are display-only; experiments can never be recorded, and no UI can set `signatureStatus='signed'`, so the tracker can never progress past pending.
4. **Signup profile header race** — after a successful signup the header/profile still render "Student / Roll No" (reproduced 3/3). Data is persisted, but the UI is stale until a reload; occasionally the recovery modal also appears despite the profile having been provided.

## 6. Findings By Domain

### 6.1 Responsive / Mobile
- No horizontal overflow at 375 / 768 / 1440. **VERIFIED.**
- Bottom nav, FAB, mobile subject accordion, formula collapse all function at 375. **VERIFIED.**
- **Mobile date navigation broken** (P1). Root cause: `index.html:205` inline `style="display:none;"` on `#mobileDateTrigger`; the responsive rule `@media (max-width:767px){ .mobile-date-trigger { display:inline-flex } }` loses to the inline style (no `!important`). No JS ever shows it.

### 6.2 Quiz System UI
- Engine + data model verified correct for cycle 1. **VERIFIED.**
- **Tab strip dead** (P1): `#quizTabs` placeholder at `index.html:218` never populated; `switchQuiz()` (`ui.js:1374`) unreachable; `app.js:605` keyboard handler operates on `.tabs-wrap .tab-btn` (none exist); summary label hard-coded `"First Quiz · "` at `ui.js:687`.

### 6.3 Laboratory UI
- Rendering correct, math correct (S3.4). **VERIFIED.**
- **No logging/signature surface** (P1): `buildLaboratorySubjectCard` (`ui.js:812`) has no action controls; global delegate handles `logLab` (`app.js:573`) but nothing emits it; nothing ever sets `signatureStatus='signed'` (engine requires it + `Attended` physical status to count completion, `laboratory-engine.js:182`).

### 6.4 Profile & Persistence
- Recovery-modal save works and persists. **VERIFIED.**
- **Signup header race** (P1): `onAuthStateChanged` renders the header before `signupUser` (`auth.js:18`) sets `AppState.profile`, and `updateProfileUI()` is never re-run on the "no cloud change" path.
- **Theme toggle reload race** (P2): cloud merge in `fetchCloudStates` (`storage.js:146`) overrides local; `triggerCloudSync` debounces the Firestore write by 1000 ms, so toggling theme and reloading within that window loses the change (reproduced; waits >1 s preserve it).
